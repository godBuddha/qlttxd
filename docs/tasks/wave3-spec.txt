=== NHIEM VU 1 — Custom pages trong shell v2 ===

Tao trong src/admin/settings/pages/:

1. WorkflowStatesPage.jsx — trang trang thai workflow:
   - Doc GET /api/v1/workflow/states
   - Bang: code, ten hien thi, is_terminal (co "Kết thúc" neu true), thu tu
   - Cho phep sua TEN HIEN THI (label) inline neu co quyen config.edit.workflow → PUT /workflow/states/:code { label } — KIEM TRA backend co endpoint nay khong; neu khong co thi hien view-only va ghi nho trong report
   - Empty state: "Chưa có trạng thái nào"

2. WorkflowTransitionsPage.jsx — ma tran chuyen trang thai:
   - GET /api/v1/workflow/transitions
   - Bang tu dong (from_state) x cot (to_state); o hop le click bat/tat; hang terminal to xam
   - Luu: PUT /api/v1/workflow/transitions/:id cho tung doi (hoac gom batch neu endpoint cho)
   - Hop xac nhan truoc khi luu: "Đổi này ảnh hưởng hồ sơ đang mở"
   - O khong ton tai: disabled + tooltip

3. RolePermissionsPage.jsx — ma tran vai tro x trang thai:
   - GET /api/v1/workflow/role-permissions
   - Grid checkbox role x 15 states; cot sticky ben trai
   - Luu bulk: PUT /api/v1/workflow/role-permissions (endpoint da co)
   - Optimistic update + rollback khi loi

4. MimeTypesPage.jsx — nhom security:
   - GET /api/v1/config?category=allowed_mime_types HOAC endpoint rieng GET /api/v1/config/mime-types (kiem tra routes/config.js da co GET allowed-mime-types — dung dung endpoint do)
   - Bang: mime_type, extension, is_active (toggle), magic_bytes_required
   - Toggle is_active → PUT cap nhat
   - Nut "Thêm" DISABLED voi tooltip: "Loại tệp mới cần cập nhật bộ kiểm tra dữ liệu thật — liên hệ đội phát triển"
   - Empty state: canh bao do "Không có loại tệp nào được phép — hệ thống sẽ từ chối mọi tệp tải lên"

5. ImportExportPage.jsx — nhom system:
   - Export: nut tai JSON (GET /api/v1/config/export) — luon mask secret
   - Import: upload file JSON → goi POST /api/v1/config/import?dryRun=true → Hien bang diff (them/sua/giu nguyen + danh sach loi validation) → nut "Xác nhận nhập" moi goi dryRun=false
   - Lich su toan cuc: GET /config/history — bang loc theo category/nguoi dung/thoi gian + nut hoan tac

6. OverviewPage.jsx — trang tong quan cua shell v2 (nang cap trang tong quan hien co):
   - The tinh trang: /health (status, db, uptime, version), so key config theo tung category
   - Danh sach 8 thay doi gan nhat tu /config/history (nguoi, luc nao, muc nao)
   - Card nhanh den cac nhom

7. PerUserPage.jsx — nhom workspace, route v2/preferences:
   - Luu scope=user qua PUT /api/v1/config/:category/:key voi header/body chi dinh scope user (KIEM TRA API co ho tro scope khong; neu khong thi luu localStorage cho theme + ghi nho trong report rang scope user se lam sau)
   - Ngon ngu (vi/en), giao dien (chi light — disabled)

Dang ky cac page nay vao manifest/shell: them entry trong settings-manifests/index.js hoac route map cua SettingsShellV2 sao cho sidebar hien dung nhu cac trang con cua nhong "workflow", "security", "system".
