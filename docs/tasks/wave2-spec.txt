=== NHIEM VU 1 — Thu muc manifest + 12 file khai bao ===

Tao thu muc app/frontend/src/admin/settings-manifests/ chua cac file JSON:

1. auth.json — nhom "security", ten "Xác thực & Phiên", icon "key-round", permission sua "config.edit.auth":
   - jwt_access_ttl: kieu duration (don vi phut/gio/ngay), nho nhat 1 phut, lon nhat 1 gio, ghi chu "Khuyến nghị ≤ 15 phút. Áp dụng cho token cấp phát mới."
   - jwt_refresh_ttl: duration, 1 ngay den 90 ngay
   - sse_token_ttl: duration, 30 giay den 10 phut
   - bcrypt_rounds: so, 10 den 14, ghi chu "Chỉ áp dụng khi tạo mật khẩu mới"
   - reset_token_expiry_ms: so (ms), 5 phut den 60 phut
   - cookie.max_age_ms, cookie.same_site (lựa chọn: lax/strict/none)

2. rate-limit.json — nhom "security", "Giới hạn tốc độ", icon "gauge", permission "config.edit.security": global_window_ms (duration), global_max, write_max, user_max, auth_max, forgot_max (so)

3. upload.json — nhom "security", "Tải lên", icon "upload": upload.max_mb (1-100), body_limit_json/body_limit_url (lua chọn kich thuoc)

4. security.json — nhom "security", "Bảo mật hệ thống": request_timeout_ms, cors_max_age, forced_shutdown_ms (so). Ghi chu rieng cho hsts_max_age neu xuat hien: "Do Caddy quản lý" (chi doc).

5. smtp.json — nhom "notification", "Email (SMTP)": smtp.enabled (bat/tat), host, port, from_address. Ghi chu tai host/port: "Thông tin đăng nhập SMTP nằm trong .env, không hiển thị tại đây"

6. notification.json — nhom "notification", "Thời gian nền": worker_batch_size, worker_poll_interval_ms, sse heartbeat_ms/poll_ms/poll_limit

7. ui.json — nhom "workspace", "Giao diện & Bản đồ": home_lat, home_lng (so thuc), language (lua chọn vi/en), theme (chi light — disabled "Sắp có")

8. pagination.json — nhom "system", "Phân trang": users_default/max, ban_do_default/max, notifications_default/max

9. cleanup.json — nhom "system", "Dọn dẹp tự động": 5 key cleanup.* (duration/so)

10. audit.json — nhom "system", "Nhật ký & Lưu trữ": audit.retention_days (canh bao neu < 365), batch_size, interval_ms

11. pool.json — nhom "system", "Hiệu năng kết nối": pool.max/idle_timeout_ms/connect_timeout_ms, ghi chu "Đổi max cần khởi động lại máy chủ để áp dụng đầy đủ"

12. features.json — nhom "advanced", "Cờ tính năng": settings_center_v2, manual_audit_purge, import_dry_run (bat/tat), permission "admin.config"

=== NHIEM VU 2 — Bo doc manifest + form tu sinh ===

1. src/admin/settings-manifests/index.js — import tat ca JSON, export mang SETTINGS_MANIFESTS da sort theo group roi order, va helper getManifest(id), getGroups() (nhom duy nha theo thu tu dinh nghia GROUP_ORDER = ["overview","workspace","security","workflow","notification","system","advanced"]).

2. src/admin/settings/GeneratedForm.jsx — component sinh form tu manifest:
   - Props: { manifest }
   - Tai du lieu: GET /api/v1/config?category=<phan dau cua key truoc dau cham> (vi key dang "auth.jwt_access_ttl" → category "auth"). Neu key co nhieu category thi goi nhieu va gop.
   - Input theo type: number → input type=number; boolean → toggle switch; enum → select; duration → input so + lua chọn don vi (phut/gio/ngay) luu thanh chuoi "15m"/"2h"/"7d"; string → input text
   - Secret field (key chua "secret"/"password"/"token"): hien thi "***" + nut hien (chi hien gia tri neu API tra ve that)
   - Trang thai: loading (khung xam), error (thong bao + nut thu lai)
   - Nut "Lưu thay đổi": chi bat khi co thay doi; goi PUT /config/bulk voi cac item da doi; thanh cong → thong bao xanh + reload; that bai → thong bao do giu nguyen du lieu
   - Moi field co label gan input, aria-describedby cho help text, aria-live="polite" cho thong bao loi
   - Keyboard: Ctrl/Cmd+S = Luu; Esc = bo cac thay doi chua luu (ve gia tri goc)

3. src/admin/settings/HistoryDrawer.jsx — drawer ben phai xem lich su 1 field:
   - Goi GET /api/v1/config/history?category=X&key=Y (kiem tra endpoint — neu chi ho tro category thi loc theo key o FE)
   - Hien danh sach: thoi gian, nguoi dung, gia tri cu → moi (dang chu ngan gon), nut "Hoàn tác về bản này" (goi POST /config/rollback/:historyId da co) co hop xac nhan
   - Mo bang nut icon lich su canh moi field; dong bang Esc; focus trap dung pattern Dialog hien co (src/components/Dialog.jsx neu co)

4. src/admin/settings/SettingsSearch.jsx — tim kiem Ctrl/Cmd+K:
   - Hop thoai overlay (dung .modal-overlay/.modal style hien co), input tim kiem
   - Du lieu index: moi field cua moi manifest (title + label + help)
   - Enter/click ket qua → dieu huong den trang do va scroll+highlight field (them vong sang qua class .field-highlight trong 2 giay)
   - Phim mui len/xuong chon, Enter mo; Esc dong; nut "Esc" hien tren giao dien

=== NHIEM VU 3 — Shell v2 + dieu huong ===

1. src/admin/settings/SettingsShellV2.jsx — bo khung moi:

   - Sidebar render TU MANIFESTS: nhom (co tieu de nhom .nav-group) → trang con; trang active theo route hien tai
   - Header moi trang: breadcrumb "Cai dat / <Nhom> / <Trang>" (link ve /admin/settings)
   - Tren cung: nut tim kiem (hien "Tìm… Ctrl+K") mo SettingsSearch
